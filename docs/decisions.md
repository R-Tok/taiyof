# 開発の決め事

太陽不動産株式会社の公式サイト更新で、実装前に揃える方針の正本です。
ステータスは次の3つです。

- **確定**: 依頼または確認で決まっていること
- **仮決定**: 確認前に開発を止めないための暫定。回答があればここを更新する
- **未決定**: まだ選んでいないこと

新しいページや共通部品を作る前に、このファイルの確定と仮決定を読むこと。

## 確定

### 進め方

- このリポジトリでフロントを中心に開発する。
- 技術は Next.js App Router、TypeScript、Tailwind CSS。モバイルを含むレスポンシブにする。
- 最初は仮デザインで実装し、後から Figma などで作ったデザインに差し替える。
- 物件情報やお知らせに加え、会社概要も運用者が CMS で更新できるようにする。CMS の候補は microCMS。
- CMS を接続するまでは、原稿を `lib/` の TypeScript 定数で管理する。接続時は取得処理を差し替え、表示側の形はできるだけ維持する。
- 仮デザインの間はページ単体で作る。共通ヘッダー・フッターはサイトマップ共有後に揃える。
- 仮の見た目はライト固定。白背景、本文は墨色、見出しのアクセントは紺。フォントは Noto Sans JP。
- 言語は日本語のみ。`html` の `lang` は `ja`。
- URL は末尾スラッシュなし（例: `/company`）。現行の `index.html` からのリダイレクトは公開前に設計する。
- 公開先は未定。ローカル開発を優先する。
- 会社情報の最初のページは `/company`。現行サイトの会社概要テーブルを内容の基準にする。
  - 現行: https://www.taiyo-f.net/company/index.html （会社概要はページ内の `#02`。`#03` はアクセス）
- 店舗からのお知らせは `/infos`（一覧）と `/infos/[slug]`（詳細）。登録日時・タイトル・本文・任意の画像を表示する。接続前の原稿は `lib/info-posts.ts`。

### 実装の置き場所

- ルートは `app/`。
- サイト共通 UI は `components/`。ページ固有の部品が増えたら `app/<path>/_components/`。
- 原稿データは `lib/`。
- 見た目だけの静的なページは Server Component。操作が必要な箇所だけ Client Component。

### 会社概要の文言

- 現行テーブルの項目と文言を転記する。電話番号だけ発信リンクにする。
- 業者登録は「宅地建物取引業者　新潟県知事（13）1633」。現行テーブルは（12）、フッターは（13）だったため、フッターの更新回数を正とした。
- 代表あいさつは現行 HTML 上でコメントアウトされ、本文がプレースホルダーのため転記しない。
- アクセス（地図）は今回の `/company` には入れない。
